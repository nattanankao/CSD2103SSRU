## 1. Recursive Partition

วิธีนี้ใช้ตัวชี้ซ้ายและขวาในการตรวจสอบข้อมูล หากค่าด้านซ้ายมากกว่า `k` และค่าด้านขวาน้อยกว่าหรือเท่ากับ `k` จะสลับตำแหน่งของข้อมูล จากนั้นเรียกเมธอดแบบเวียนเกิดต่อไปจนกว่าตัวชี้ทั้งสองจะพบกัน

## 2. Iterative Partition

วิธีนี้ใช้หลักการเดียวกับ Recursive Partition แต่เปลี่ยนจากการเรียกเมธอดแบบเวียนเกิดมาใช้ลูป `while` แทน จึงทำงานได้เหมือนกันแต่ไม่ต้องใช้ Call Stack

## 3. Sorting-Based Algorithm

วิธีนี้จะเรียงข้อมูลทั้งหมดก่อน แล้วหาตำแหน่งสุดท้ายที่มีค่าน้อยกว่าหรือเท่ากับ `k` หลังจากเรียงเสร็จ ข้อมูลจะเรียงจากน้อยไปมาก ซึ่งต่างจากสองวิธีแรกที่เพียงแบ่งข้อมูลออกเป็นสองกลุ่มโดยไม่จำเป็นต้องเรียงลำดับ

## 4. Time Complexity

- Recursive Partition : **O(n)**
- Iterative Partition : **O(n)**
- Sorting-Based Algorithm : **O(n log n)**

Recursive และ Iterative ตรวจสอบข้อมูลแต่ละตัวเพียงครั้งเดียว ส่วน Sorting-Based ต้องเรียงข้อมูลก่อน จึงใช้เวลามากกว่า

## 5. Space Complexity

- Recursive Partition : **O(n)** (ใช้ Call Stack)
- Iterative Partition : **O(1)**
- Sorting-Based Algorithm : **O(log n)**

Recursive ใช้พื้นที่เพิ่มจากการเรียกเมธอดแบบเวียนเกิด ส่วน Iterative ใช้ตัวแปรเพียงไม่กี่ตัว ขณะที่ `Arrays.sort()` สำหรับ `int[]` ใช้พื้นที่เพิ่มเติมประมาณ O(log n) จากการทำงานภายในของอัลกอริทึมเรียงลำดับ

## 6. เหตุผลที่การเรียงลำดับอาจทำให้โปรแกรมช้ากว่าที่จำเป็น

โจทย์ต้องการเพียงแบ่งข้อมูลออกเป็นสองกลุ่ม คือค่าที่น้อยกว่าหรือเท่ากับ `k` และค่าที่มากกว่า `k` เท่านั้น ไม่ได้ต้องการเรียงข้อมูลทั้งหมด ดังนั้นการเรียงข้อมูลก่อนจึงทำให้เสียเวลาเพิ่มโดยไม่จำเป็น เมื่อเทียบกับวิธี Recursive และ Iterative ที่สามารถแบ่งข้อมูลได้ทันที

## 7. ความสัมพันธ์กับขั้นตอน Partition ใน Quick Sort

Recursive Partition และ Iterative Partition ใช้หลักการเดียวกับขั้นตอน Partition ของ Quick Sort คือใช้ตัวชี้สองตำแหน่งในการแบ่งข้อมูลออกเป็นสองส่วน เพียงแต่ในโจทย์นี้ใช้ค่า `k` เป็นตัวแบ่ง แทนที่จะใช้ Pivot เหมือนใน Quick Sort

## 8. อัลกอริทึมที่สามารถทำงานแบบ In-place

- Recursive Partition : **เป็น In-place Algorithm**
- Iterative Partition : **เป็น In-place Algorithm**
- Sorting-Based Algorithm : **เป็น In-place Algorithm** (ในโค้ดนี้ใช้ `Arrays.sort(int[])` ซึ่งเรียงข้อมูลในอาร์เรย์เดิม)

ทั้งสามวิธีสามารถทำงานกับอาร์เรย์เดิมได้ โดยไม่ต้องสร้างอาร์เรย์ใหม่สำหรับเก็บผลลัพธ์
