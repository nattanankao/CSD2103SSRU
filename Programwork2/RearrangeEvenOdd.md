## 1. Time Complexity

ทั้ง 3 วิธีมี Time Complexity เป็น **O(n)** เพราะต้องตรวจสอบสมาชิกทุกตัวในอาร์เรย์อย่างน้อย 1 ครั้ง แม้ว่า Extra Array จะวนลูป 2 รอบ แต่ก็ยังถือว่าเป็น O(n)

## 2. Space Complexity

Recursive Two-Pointer มี Space Complexity เป็น **O(n)** เพราะมีการเรียกเมธอดแบบเวียนเกิด ทำให้ใช้พื้นที่ของ Call Stack เพิ่มขึ้นตามจำนวนข้อมูล

Iterative Two-Pointer มี Space Complexity เป็น **O(1)** เพราะใช้ตัวแปรเพิ่มเติมเพียงไม่กี่ตัว และไม่สร้างอาร์เรย์ใหม่

Extra Array มี Space Complexity เป็น **O(n)** เพราะต้องสร้างอาร์เรย์ใหม่สำหรับเก็บผลลัพธ์

## 3. จำนวนครั้งของการสลับข้อมูล

Recursive Two-Pointer และ Iterative Two-Pointer จะสลับข้อมูลเมื่อพบว่าด้านซ้ายเป็นจำนวนคี่และด้านขวาเป็นจำนวนคู่ จำนวนครั้งในการสลับขึ้นอยู่กับตำแหน่งของข้อมูลในอาร์เรย์

Extra Array ไม่มีการสลับข้อมูล แต่จะคัดลอกข้อมูลไปเก็บในอาร์เรย์ใหม่แทน

## 4. การเปลี่ยนแปลงอาร์เรย์เดิม

Recursive Two-Pointer และ Iterative Two-Pointer จะเปลี่ยนแปลงข้อมูลในอาร์เรย์เดิม เนื่องจากใช้การสลับตำแหน่งของสมาชิก

Extra Array จะไม่เปลี่ยนแปลงอาร์เรย์เดิม แต่สร้างอาร์เรย์ใหม่ขึ้นมาเพื่อเก็บผลลัพธ์

## 5. ความเป็น Stable Algorithm

Recursive Two-Pointer และ Iterative Two-Pointer ไม่เป็น Stable Algorithm เพราะการสลับข้อมูลอาจทำให้ลำดับเดิมของจำนวนคู่หรือจำนวนคี่เปลี่ยนไป

Extra Array เป็น Stable Algorithm เพราะนำจำนวนคู่และจำนวนคี่ไปเก็บตามลำดับเดิมของข้อมูล ทำให้ลำดับของสมาชิกไม่เปลี่ยน

## 6. การรักษาลำดับเดิมของสมาชิก

จากการทดสอบพบว่า มีเพียง **Extra Array** ที่สามารถรักษาลำดับเดิมของสมาชิกได้

ตัวอย่าง

Input:
```
[5,2,7,4,9,6]
```

Stable Output:
```
[2,4,6,5,7,9]
```

จากตัวอย่างจะเห็นว่า จำนวนคู่ยังคงเรียงเป็น `2,4,6` และจำนวนคี่ยังคงเรียงเป็น `5,7,9` เหมือนกับลำดับในอาร์เรย์เดิม จึงถือว่าเป็น Stable Algorithm
