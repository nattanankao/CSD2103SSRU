# คำตอบงานวิเคราะห์ Bubble Sort

## 4. วิเคราะห์กรณีข้อมูลเรียงแล้ว

ตัวอย่างข้อมูล: `91, 88, 79, 72, 65`

-   เรียงข้อมูลกมากไปน้อยอยู่แล้ว จึงไม่มีการสลับข้อมูล (`Swap = 0`)
-   Bubble Sort **แบบปกติ** ยังเปรียบเทียบข้อมูลจนครบทุกรอบ จึงมีเวลาในการทำงาน
    **O(n²)**
-   Bubble Sort **แบบปรับปรุง (ใช้ตัวแปร `swapped`)**
    จะหยุดหลังจบรอบแรกเมื่อไม่มีการสลับข้อมูล ทำให้ Best Case เหลือ **O(n)**



## 5. วิเคราะห์กรณีข้อมูลเรียงย้อนกลับ (Worst Case)

ตัวอย่างข้อมูล: `65, 72, 79, 88, 91`

-   ข้อมูลเรียงตรงข้ามกับลำดับที่ต้องการ จึงต้องสลับข้อมูลหลายครั้ง
-   ทั้ง Bubble Sort แบบปกติและแบบปรับปรุงต้องทำงานจนครบทุกรอบ
-   เวลาในการทำงานของทั้งสองแบบเป็น **O(n²)**



# คำถามวิเคราะห์

## 1. Bubble Sort แบบปกติกับแบบปรับปรุงมี Best Case ต่างกันอย่างไร

Bubble Sort แบบปกติจะเปรียบเทียบข้อมูลจนครบทุกรอบ แม้ว่าข้อมูลจะเรียงอยู่แล้ว จึงมี Best
Case เป็น **O(n²)**

ส่วน Bubble Sort แบบปรับปรุงจะใช้ตัวแปร `swapped` ตรวจสอบว่ามีการสลับข้อมูลหรือไม่
หากไม่มีการสลับ โปรแกรมจะหยุดทันที ทำให้ Best Case เหลือ **O(n)**



## 2. Worst Case ของทั้งสองวิธีต่างกันหรือไม่

ไม่ต่างกัน เพราะเมื่อข้อมูลเรียงย้อนกลับ จะมีการสลับข้อมูลในทุก ๆ รอบ
ทำให้ทั้งสองวิธีต้องทำงานจนครบและมีเวลาในการทำงาน **O(n²)**



## 3. หากมีข้อมูลจำนวน 100,000 ค่า ควรเลือกวิธีนี้หรือไม่

ไม่ควร เพราะ Bubble Sort มีความซับซ้อน **O(n²)**
ทำให้จำนวนการเปรียบเทียบเพิ่มขึ้นอย่างมากเมื่อข้อมูลมีขนาดใหญ่ ส่งผลให้ใช้เวลานาน

หากต้องเรียงข้อมูลจำนวนมาก ควรเลือกอัลกอริทึมที่มีประสิทธิภาพกว่า เช่น Merge Sort,
Quick Sort (โดยเฉลี่ย) หรือ Heap Sort ซึ่งมีเวลาในการทำงานประมาณ **O(n log
n)**
